# Solutions

The three notebooks, solved and run, with sample answers to every 🧠 question. Try first, then compare your reasoning, not just your numbers.

| File | Description |
|---|---|
| [**1 - Your First Tree**](1_first_tree.ipynb) | Baseline, rule, mixing scores, first question, depth-2 tree, leaf scores and threshold. |
| [**2 - Depth and Knobs**](2_depth_and_knobs.ipynb) | Overfitting, depth sweep with cross-validation, knobs, final test, threshold under capacity. |
| [**3 - PM Decisions**](3_pm_decisions.ipynb) | Leak, rules, model comparison, recall per group, causation, recommendation. |

> The solution notebooks read the data from `../data/`.
